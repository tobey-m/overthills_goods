# OVERTHILL — Stripped Back / v4

ปรับจาก v3: ดำหมึก–ขาวหม่น ตัวอักษรตรงและหนัก เสื้อวางตรง ลบวงกลมและป้ายตกแต่ง ลดสีเขียวและข้อความที่อ่อนหวาน คงแก่นเรื่องเดิมและระบบ shortlist

รายละเอียดพื้นฐาน
เปิด index.html ได้ทันที หรือเผยแพร่เป็น static website บน Vercel (Framework: Other, ไม่ต้อง build; เลือกโฟลเดอร์ที่มี index.html เป็น root)

## ฉบับนี้
- หน้าเว็บภาษาอังกฤษทั้งหมด ใช้ Space Grotesk น้ำหนัก 400/600/700 ตามต้นฉบับ
- ธีมดำ–ครีม แทรกเขียวหม่นเมื่อเลือก Trail
- Hero Run Ran Run และรูปต้นฉบับขนาดใหญ่
- สลับ Road / Trail และ Front / Back พร้อมขยายภาพ
- แสดงเรื่องราวในหน้าเว็บ: Ginger Root / Over the Hill, ร้านมือสอง Zhongshan ในไต้หวัน, street running lifestyle, วิ่งแล้วแวะคาเฟ่
- คงแนวคิด RUN = เริ่ม/กำลังวิ่ง, RAN = ประสบการณ์/พักฟื้น, RUN = วงจรกลับมาวิ่ง
- คงคำเล่นเดิม “this shirt was made to ran” ในคำอธิบาย ไม่มีการแก้ภาพ SVG ต้นฉบับ
- รายการที่สนใจจำในเบราว์เซอร์ ลบได้ คัดลอกไปสอบถาม Instagram ด้วยตนเอง ไม่มีการส่งข้อความอัตโนมัติ
- ราคา สี และไซซ์ยังเป็นข้อมูลเบื้องต้น ไม่รับเงินหรือสร้างออร์เดอร์

## แก้ไขต่อ
products ใน script กำหนดรุ่น ชื่อ คำอธิบาย และตำแหน่งลาย
unitPrice กำหนดราคา ปัจจุบัน 590 บาท; ราคาในส่วน product-info ของ HTML ต้องปรับให้ตรงกันด้วย
ไฟล์รูปอยู่ใน img และใช้ชื่อเดิม เพื่อรักษางานออกแบบดั้งเดิม
ตัวเลือกสีเป็นความสนใจเบื้องต้น ไม่เปลี่ยนสีภาพเสื้อ เพราะยังไม่มีภาพแยกแต่ละสี
Google Fonts ต้องใช้อินเทอร์เน็ต หากออฟไลน์เบราว์เซอร์ใช้ sans-serif สำรอง

## ผลตรวจ
ตรวจ JavaScript syntax, Space Grotesk โหลดได้จริง, ภาพสินค้าโหลดสำเร็จ, ไม่มีข้อความไทยบนหน้าเว็บ และไม่มีการล้นแนวนอนบน viewport เดสก์ท็อปที่ตรวจ
ทดสอบ Road/Trail, เพิ่มรายการตามรุ่นที่เลือก, 2 ตัวรวม 1,180 บาท และ dialog ขยายภาพ
รองรับมือถือผ่าน responsive CSS แต่ยังไม่ตรวจบนอุปกรณ์มือถือจริง
ก่อนรับเงินจริงต้องยืนยันผ้า ทรง ขนาด เงื่อนไข และพัฒนาหลังบ้านที่ยืนยันการบันทึกออร์เดอร์ได้
